# Идея №13: удобный интерфейс протоколиста

## Функционал
- Лента реплик встречи с временными метками.
- Встроенный аудиоплеер и быстрый переход к фрагменту по таймкоду.
- Удобный режим для фиксации ключевых договоренностей и решений.

## Бизнес-ценность
- Сокращение времени на подготовку протоколов после встречи.
- Повышение качества follow-up и прозрачности исполнения договоренностей.

## Шаги реализации
1. Добавить timeline-сущность сообщений встречи с таймкодами.
2. Интегрировать аудио-плеер с переходом по времени.
3. Добавить actions для заметок/экспорта протокола.
4. Протестировать на длинных записях и больших встречах.
