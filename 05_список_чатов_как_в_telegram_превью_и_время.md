# Проблема №5: список чатов как в Telegram (превью последнего сообщения + время)

## Цель

Сделать список чатов в Клаве более информативным и привычным:

- показывать не только название чата, но и строку последнего сообщения;
- показывать время/дату последней активности в компактном формате;
- визуально приблизить поведение к Telegram-паттерну.

---

## Что уже реализовано в прототипе

- В новом списке чатов (new room list) добавлено отображение времени последнего сообщения справа от названия.
- Добавлена логика форматирования времени:
  - сегодня -> `HH:MM`;
  - ранее (до 6 дней включительно) -> `пн/вт/ср/...`;
  - старше -> `dd.mm.yy`.
- Включен показ превью последнего сообщения в новом списке чатов.
- Увеличена высота строки чата, чтобы помещались 2 строки:
  - верхняя: название + время;
  - нижняя: текст последнего сообщения.

---

## Scope (продуктовый)

### S1. Отображение времени последнего сообщения

- Время берется из последнего события в комнате.
- Формат строго по правилам UX:
  - today: `HH:MM`
  - 1..6 дней назад: `weekday short`
  - 7+ дней назад: `dd.mm.yy`

### S2. Превью последнего сообщения

- Для каждого чата показывается вторая строка с текстом последнего сообщения.
- Текст обрезается с `...`, без переноса на 2+ строки.

### S3. Верстка списка

- Элемент списка чата адаптируется под 2 строки.
- Название и timestamp не конфликтуют и не “прыгают”.

## Инструкции разработчикам (человеческие)

### Задача A (время)

1. Использовать единственный источник timestamp (последнее live-событие комнаты).
2. Вынести форматирование в отдельную функцию (без дублирования между компонентами).
3. Проверить часовой пояс пользователя (локальное время браузера).
4. Проверить граничные моменты (смена дня в 00:00).

### Задача B (превью)

1. Привязать превью к MessagePreviewStore для new room list.
2. Убедиться, что preview не исчезает из-за legacy-настройки, если продукт ожидает always-on.
3. Для пустых/неподдерживаемых событий показывать пустую вторую строку без ошибок.

### Задача C (верстка)

1. Сделать строку названия с правым timestamp в одной оси.
2. Настроить `text-overflow: ellipsis` для названия и preview.
3. Поддержать совместимость с индикаторами уведомлений и кнопками меню.
4. Прогнать визуальный smoke на основных разрешениях.
