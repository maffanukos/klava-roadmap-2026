# Prompt для ИИ: Идея #10 (уведомить, когда пользователь в сети)

Реализуй feature подписки на online-статус контакта в `element-web`.

## Требования
- В контекстном меню контакта:
  - `Уведомить, когда будет в сети`;
  - `Не уведомлять, когда будет в сети`.
- При смене статуса выбранного пользователя на `online` показать уведомление с кнопками:
  - `Чат`,
  - `Позвонить`.
- Хранить подписки пользователя локально (MVP), позже расширяем до server sync.

## Результат
1. Список измененных файлов.
2. Кратко: где хранится подписка, где ловится presence, где показывается уведомление.
3. QA checklist.
