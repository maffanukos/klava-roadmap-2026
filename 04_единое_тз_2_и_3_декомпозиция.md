# Единое ТЗ 2+3: Центр встреч + русификация + модалка + участники + занятость

## Цель

Собрать в единый продуктовый контур все, что было задумано в ТЗ 2 и реализовано/уточнено в ТЗ 3:

- новый центр встреч `ВКС` с вкладками `Запланированные`/`История`;
- создание и планирование встреч через единый мастер;
- подбор участников из зарегистрированных пользователей Клавы;
- визуализация занятости при планировании;
- русификация ключевого интерфейса;
- логичная навигация в левой панели.

---

## Scope (объединенный)

### S1. Центр встреч

- Вкладки: `Запланированные`, `История встреч`.
- Верхние действия: `Начать встречу`, `Запланировать встречу`.
- Для истории: дата/время, название, воспроизведение записи, открытие конспекта.
- Для запланированных: запуск, редактирование, удаление, копирование ссылок (внутренняя/внешняя).

### S2. Мастер встречи (единая модалка)

- Режимы: `start`, `schedule`, `edit`.
- Поля: название, участники, тип встречи, комната ожидания.
- Для `schedule/edit`: дата и время + блок занятости.
- Модалка открывается поверх интерфейса (overlay), не двигает layout.

### S3. Участники

- Поиск и выбор из зарегистрированных пользователей Клавы.
- Подсказки, добавление/удаление выбранных участников.
- Подготовка к статусам `в звонке / не в звонке / приглашен / отклонил`.

### S4. Занятость

- UI-диаграмма занятости для режима планирования.
- На текущем этапе: mock-режим визуализации.
- На следующем этапе: замена на реальные календарные данные через API.

### S5. Русификация и навигация

- Русские подписи ключевых элементов ВКС и левой панели.
- Порядок в левой панели: `Сообщения -> ВКС -> Контакты`.
- Разделитель и заголовок `Комнаты`.

## Декомпозиция по задачам (единый backlog)

## Epic A. UI/UX центра встреч

### A1. Экран `ВКС`: вкладки и верхняя панель действий

**Подзадачи:**

- A1.1 Рендер вкладок `Запланированные`/`История`.
- A1.2 Переключение датасетов и состояния пустых списков.
- A1.3 Верхние кнопки `Начать встречу`/`Запланировать встречу`.
- A1.4 Удаление legacy-кнопок и дублей в тулбаре.

**Definition of Done:**

- вкладки работают стабильно;
- UI не содержит дублирующих кнопок;
- тексты соответствуют русскому UX.

### A2. Ряды встреч и действия

**Подзадачи:**

- A2.1 История: запись/конспект.
- A2.2 Запланированные: старт/редактирование/удаление.
- A2.3 Копирование двух ссылок: внутренняя/внешняя.
- A2.4 Обработка ошибок действий (нет записи, нет прав, таймаут).

**Definition of Done:**

- все действия доступны из строки;
- после действия UI обновляется без ручного рефреша.

## Epic B. Мастер создания/планирования

### B1. Единая модалка в 3 режимах

**Подзадачи:**

- B1.1 Режим `start`: создание и старт.
- B1.2 Режим `schedule`: создание запланированной встречи.
- B1.3 Режим `edit`: редактирование существующей встречи.
- B1.4 Валидация обязательных полей.

### B2. Overlay и компоновка без лишнего скролла

**Подзадачи:**

- B2.1 Backdrop (dim + blur), центрирование, z-index.
- B2.2 Закрытие через `X`, `Esc`, клик по фону.
- B2.3 Адаптивные размеры (start компактнее, schedule шире).
- B2.4 Фикс внутренних отступов и вертикального ритма.

**Definition of Done:**

- модалка не сдвигает экран;
- на целевых разрешениях нет лишней прокрутки в типовых сценариях.

- ошибки календаря не блокируют создание встречи.

**Цель:** заменить mock занятости на реальную интеграцию календаря.

- при успехе показываются реальные данные;
- при ошибке включается безопасный fallback (“данные недоступны”, но встречу можно сохранить);

- логируются технические ошибки интеграции.
