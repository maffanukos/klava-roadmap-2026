# Prompt для ИИ: Идея #12 (управление раскладкой конференции)

Реализуй расширенное управление раскладкой в видеоконференции.

## Требования
- Drag-and-drop окон участников в текущей сетке.
- Pin приоритетного участника.
- Опции в настройках раскладки:
  - авто-смена приоритетного по голосу;
  - скрывать участников без видео.

## Результат
1. Список измененных файлов.
2. Описание структуры layout state.
3. QA checklist по сценариям конференции.
