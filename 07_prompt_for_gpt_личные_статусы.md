# Prompt для ИИ: ТЗ #7 (личные статусы)

Ты senior frontend/backend engineer в проекте `element-web`.

## Цель

Реализовать личные статусы пользователя с полным циклом:
- создание;
- редактирование;
- срок действия;
- сброс;
- показ в меню, шапке пользователя и профиле.

## Функциональные требования

1. Эмодзи — произвольный.
2. Текст статуса — до 100 символов (включая пробелы).
3. Срок статуса:
   - готовые пресеты;
   - точная дата и время;
   - “Показывать всегда”.
4. Сброс статуса по `×` и отдельной кнопкой.
5. Возможность редактирования эмодзи, текста и срока после создания.
6. Отображение:
   - в user menu;
   - в шапке пользователя слева;
   - в UserInfo профиле (для других пользователей, если поддерживается сервером).

## Технические требования

- Сделать компактный UI в `UserMenu` (без развала по высоте экрана).
- Реализовать слой хранения статуса:
  - локально (быстрый отклик);
  - публикация через presence/status message;
  - fallback через account data при серверных ограничениях.
- Добавить автоистечение статуса по времени.

## Ограничения

- Не ломать текущие меню-опции пользователя.
- Не делать нерелевантный глобальный рефакторинг.
- Изменения — минимально инвазивные и ревьюопригодные.

## Формат результата

1. Список измененных файлов.
2. Что сделано по UI.
3. Что сделано по data-layer.
4. Как реализовано автоистечение.
5. Какие edge-cases покрыты.
6. QA checklist (8-12 пунктов).
