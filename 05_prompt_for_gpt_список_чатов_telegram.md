# Prompt для ИИ: ТЗ #5 (список чатов как в Telegram)

Ты senior frontend engineer в проекте `element-web`.

## Цель

В новом списке чатов (`new room list`) реализовать Telegram-паттерн:

1. первая строка: название чата + время/дата последнего сообщения справа;
2. вторая строка: превью последнего сообщения.

## Правила времени (обязательные)

- Если сообщение сегодня: `HH:MM`
- Если сообщение не сегодня, но в диапазоне последних 6 дней: `пн/вт/ср/чт/пт/сб/вс`
- Если старше: `dd.mm.yy`

## Ограничения

- Работать только в контуре `new room list` (не legacy room tile).
- Не менять бизнес-логику открытия чатов, контекстных меню, уведомлений.
- Не делать массовый рефакторинг стилей.

## Технические требования

1. Источник timestamp — последнее live-событие комнаты.
2. Реактивное обновление при приходе новых событий.
3. Превью последнего сообщения должно отображаться стабильно (в рамках текущего продуктового решения).
4. Верстка room item должна поддерживать 2 строки, корректный ellipsis и совместимость с badge/menu.

## Формат результата

1. Список измененных файлов.
2. Кратко: что сделано в логике времени.
3. Кратко: что сделано в превью.
4. Кратко: что сделано в верстке.
5. Checklist ручной проверки (5-8 пунктов).
